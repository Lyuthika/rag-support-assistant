\# Intro to databases



Source URL: https://www.notion.com/help/intro-to-databases



Category: databases



Databases in Notion are collections of pages. They help you manage and organize multiple pages in one place.



Every item you enter into a database is a Notion page. You can open a database item to add more information such as text, images, and other content.



You can customize database properties to contextualize, label, and augment database items with information such as dates, status, and links.



You can visualize your data in different ways. A database can be organized as a table, list, calendar, chart, and other views.



You can view multiple sets of data in one database. For example, you can build an all-in-one CRM database where contacts, companies, and deals are managed in one database.



\## Create a database



To create a database in Notion, create a new page and under Get started with, select Table. You can also open an existing page and use the slash command /database.



When you create a database, you can start from scratch or use an existing data source from your workspace.



Creating a new database can also provide options to use a suggested template or build a database with AI.



\## Set up a database



1\. Create a new database page by clicking New page to add a new page to your database.



2\. Add a property to give your database more ways to organize each page. For example, a task database might include a status property and a due date property.



3\. Add a new view. Views allow you to organize the information in your database in different ways. By default, a database is displayed in Table view, but you can add additional views.



4\. Edit your view. You can edit its name, layout, visible properties, filters, sorts, and groups.



\## Collaborating in a database



When using a database in a shared workspace, Notion provides permission controls.



The Can edit content permission level allows users to create, edit, and delete pages within the database and edit property values for those pages.



Users with Can edit content permissions cannot add, edit, or remove database properties or views, change filters or sorts, or lock or unlock the database.



\## Lock views



The lock option can be found in the three-dot menu at the top right of the Notion window.



Turning on the lock prevents people from changing properties and views in the database. Users can still edit the data contained in the database.



\## Database pages



Every item in a database is its own Notion page. Database items can contain text, images, and other content just like other Notion pages.
